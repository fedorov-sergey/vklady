# AGENTS.md — Сравнение банковских вкладов

## О проекте
Статический сайт на GitHub Pages, сравнивающий ставки по вкладам и накопительным счетам банков.
Целевой пользователь — человек с 1 000 000 ₽, ищущий оптимальный вариант по доходности,
с учётом своих особенностей (траты, подписки, новые деньги и т.д.).

## Стек
- **Данные**: `Вклады.xlsx` (обновляется вручную раз в неделю)
- **Сборка**: `build.py` — Python + openpyxl; генерирует `docs/data.json`
- **Сайт**: `docs/index.html` + `docs/app.js` + `docs/style.css` — чистый JS, без фреймворков
- **Хостинг**: GitHub Pages (источник — папка `docs/` на ветке master)
- **CI**: `.github/workflows/build.yml` — автоматическая пересборка data.json при пуше xlsx

## Схема данных

### Правила нормализации (build.py)
1. **Проценты**: если значение в диапазоне (0, 1] и не содержит '%' → умножить на 100.
   0.12 → 12, 0.095 → 9.5, 12.39 → 12.39.
2. **Формулы** (начинаются с '='): пропустить (build.py берёт следующий источник ставки).
3. **Сроки**: <60 → месяцы; ≥60 → дни (пересчитываем в месяцы: round(days/30.44)).
4. **ЦБ-дельта**: парсится строка, символ '=' и '%' убирается; значения как проценты.

### Приоритет источника ставки
build.py перебирает колонки в порядке:
1. U — Ставка при открытии (счета)
2. N — Ставка с капитализацией при открытии (вклады)
3. K — Ставка с капитализацией
4. J — Ставка без Капитализации
5. X — Ставка Новые деньги Надбавка (максимальная при новых деньгах)

### Модель «база + надбавки»
- **Траты/мес**: каждая строка хранит порог (0, 20000, 100000).
  Строка «траты ≥20000» даёт ставку 10.5%, строка «траты = 0» — 7%.
  На сайте пользователь выбирает свой порог, фильтр показывает подходящие строки.
- **Подписка** (Т-Банк): каждая подписка — отдельная строка со своей ставкой.
- **Новые деньги** (ГПБ): строка хранит rate (надбавка) и rate_base (база).
  На сайте toggle «все деньги новые» переключает между ними.

## Как обновить данные
1. Отредактировать `Вклады.xlsx` (в формулах — вставить значения!)
2. Запустить:
   ```bash
   python build.py
   ```
3. Проверить, что `docs/data.json` обновился
4. Закоммитить:
   ```bash
   git add Вклады.xlsx docs/data.json
   git commit -m "data: обновление ставок YYYY-MM-DD"
   git push
   ```
5. GitHub Actions пересоберёт сайт автоматически (или commit push обновит data.json)

## Команды
```bash
python build.py          # пересобрать docs/data.json из Вклады.xlsx
python -m http.server 8000 -d docs   # локальный сервер для проверки
```

## Конвенции
- Все ставки в data.json — в процентах (7.0 = 7%, 12.39 = 12.39%)
- Сроки в duration_months (int|null)
- Не править `docs/data.json` руками — только через build.py
- Не удалять строки из Excel — при последующей сборке build.py перезапишет data.json
